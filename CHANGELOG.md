# Changelog

## 0.1.0 (unreleased)

- First version of the Gender-API node.
- Gender by first name, full name and email address, with country, locale and IP localization.
  Several input items go to Gender-API in one request (up to 100 names, 'Batch Size' option).
- Country of origin by first name, full name and email address.
- Account statistics (remaining credits, usage last month).
- Credential with a test request against the free `/v2/statistic` endpoint.
- Usable as a tool for the AI Agent node.
